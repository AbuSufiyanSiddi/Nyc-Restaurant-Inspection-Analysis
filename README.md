# Nyc-Restaurant-Inspection-Analysis
• NYC Restaurant Inspection Analysis: cleaned 300K+ records in Power Query and built an interactive Power BI dashboard to find high-risk boroughs and common food-safety violations.
Business Scenario

Role: Data Analyst for the NYC Department of Health and Mental Hygiene and a group of restaurant management companies. The client wanted data-driven answers on food safety patterns across the city.

Questions Answered
Which borough has the highest number of restaurant violations?
Which cuisine categories receive the most violations?
How do inspection trends change over time?
Which violation types occur most frequently?
How do grades and inspection scores differ across boroughs?
Dataset
Source: NYC restaurant inspection results (public NYC data)
Size: about 300K records, 27 columns; each row is a violation recorded during an inspection
Key fields: CAMIS, DBA, BORO, CUISINE DESCRIPTION, INSPECTION DATE, INSPECTION TYPE, VIOLATION CODE, VIOLATION DESCRIPTION, CRITICAL FLAG, SCORE, GRADE, ACTION
Tools

Power BI, Power Query, DAX, Data Modeling

Data Cleaning (Power Query)
Corrected column structure and data types
Trimmed extra whitespace in text fields
Removed duplicate records
